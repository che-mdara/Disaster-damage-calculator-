Data and deployment notes

  • Records are stored in this browser on this device. There is no automatic cloud sync or shared district database.
  • GPS capture requires browser permission and may require HTTPS or a supported browser context; manual coordinates are available.
  • Exported files can contain sensitive data. Store and share them only under approved council procedures.
  • For actual district deployment, add a managed backend, authenticated user accounts, server-side permissions, encrypted transport/storage, protected audit logs, tested backups and a written data-retention policy.
  • Use the current approved government assessment forms and obtain authorisation before collecting real household data.

Delete-all is irreversible unless a backup exists and will ask for confirmation.
